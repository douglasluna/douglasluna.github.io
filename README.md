# Douglas Luna Personal Blog

A Jekyll/Chirpy personal blog customized for Douglas Luna and ready for GitHub Pages.

## GitHub Pages

Push this repository to GitHub and enable Pages with **GitHub Actions** as the source. The workflow in `.github/workflows/pages-deploy.yml` builds and deploys the site on pushes to `main` or `master`.

## Local Preview

Use Ruby 3 to preview the site locally:

```sh
bundle install
bundle exec jekyll serve
```
